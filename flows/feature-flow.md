# Feature Flow

Default flow for normal feature work.

1. Frame goal, scope, non-goals, acceptance criteria, and verification.
2. Check whether a project issue, PRD, or plan item is required.
3. Decide whether implementation belongs in the main thread or a specialist
   subthread.
4. Implement the smallest coherent slice.
5. Run relevant verification.
6. Apply Completion Gate.
7. Apply Risk Gate based on risk level.
8. Prepare a concrete human acceptance guide.
9. Ship only according to the project merge rules.
